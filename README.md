Magic The Gathering Deck List
The end goal of this project is to have a site where I can easily list all of my current decks, adjust the contents, and add new decks.


## Planned Data Model
I plan on having different decks labeled with a title, description and when clicked display the decklist.

## Project Progress Week 3:
The page is structured to have a bar at the top for the header containing the page title

## Project Progress Week 4:
I have styled the page in a darker tone to allow the colors of the individual decks to pop more on the screen. The decks are to be displayed in a flex box while maintaining the image size so it doesnt get strecthed or distorted. Eventually I would like to be able to click on each individual deck to go to a seperate page for the deck. To signify this, I have made it so when you hover over the deck in with "float" above the background.

## Project Progress Week 6:
Created app.js and linked it near the bottom of the body in index.html
Created variables to track how man decks are posted and store the name and mana value of the commander. The for loop is used to print the info for each deck and also sum the mana cost of each for an average of all.

## Project Description:
This site is designed to store multiple decks and store information including: deck name, color(s), format, and decklist. I will be able to select each deck from the home screen and edit each deck individually

## Current Features:
Future plans are to be able to input information to add new decks, including deck lists, and adjust preexisting decks.
